# Zapret GUI

Удобный графический интерфейс для [zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube) (автор движка — Flowseal). Приложение не заменяет zapret, а управляет им: запускает `winws.exe` с нужными аргументами, автоматически подбирает рабочую стратегию и следит за состоянием.

## Возможности

- **Автоподбор рабочей стратегии** — последовательный перебор стратегий с реальной проверкой доступа к Discord и YouTube.
- **Большой выбор стратегий** — список строится автоматически из `.bat`-файлов zapret.
- **Служба Windows** — установка / удаление.
- **Автозапуск с Windows** + запуск свёрнутым в трей.
- **Трей с индикатором состояния** (зелёный / красный / жёлтый).
- **Обновление стратегий из репозитория** Flowseal (с сохранением пользовательских стратегий).
- **Самообновление приложения** — кнопка «Обновить приложение» в Настройках проверяет GitHub Releases, показывает прогресс загрузки в процентах, сверяет SHA-256 скачанного установщика с опубликованным и только потом запускает его.
- **Редактор** своих стратегий и списков доменов / ipset.
- **Telegram MTProto-прокси** — движок `tg-ws-proxy` (от того же Flowseal) **встроен прямо в приложение как Python-модуль** — никакого отдельного процесса и второй иконки в трее. Отдельный таб с тумблером, статусом, кнопками «Скопировать ссылку» / «Открыть в Telegram» и опцией автозапуска вместе с zapret.
- **Пресеты игр и сервисов** — выборочно применять обход к Roblox, Steam, Epic Games, Battle.net, FACEIT, SoundCloud (с полным списком API + media + CDN доменов) или наоборот исключить их. Свои домены — через запятую.
- **10 тем оформления** — 3 классические (Фиолетовая / Тёмная / Светлая) + 7 новых с фоновыми изображениями (Туман, Лазурь, Снег, Лаванда, Дымка, Песок, Полночь). Выбор через dropdown-меню в Настройках; каждая тема подбирает цвета карточек, текста и акцентов под свой фон. Расположение элементов одинаковое во всех темах (эталон — Тёмная); визуальная унификация части второстепенных элементов ещё продолжается.
- **Логирование** — диагностика (в т.ч. Telegram-прокси) пишется в файл `%LOCALAPPDATA%\ZapretGUI\logs\zapret-gui.log` с ротацией, что упрощает разбор проблем без пересборки приложения.

## Размещение

Положите папку `zapret-gui` **рядом** с распакованным zapret-discord-youtube:

```
...\
  zapret-discord-youtube\   <- здесь bin\winws.exe, *.bat, lists\
  zapret-gui\               <- это приложение
```

Папка zapret определяется автоматически (ищется `bin\winws.exe`). Если не нашлась — укажите её во вкладке «Настройки».

## Запуск из исходников

Требуется Python 3.10+ и Windows 10/11.

```bat
pip install -r requirements.txt
python main.py
```

Приложению нужны права администратора (драйвер WinDivert). При запуске оно само запросит UAC.

## Сборка .exe

```bat
build.bat
```

или вручную:

```bat
pip install pyinstaller
pyinstaller zapret-gui.spec --noconfirm
```

Результат — `dist\ZapretGUI.exe` (один файл, без консоли, с запросом админа).

## Как работает автоподбор

1. Берёт стратегии в порядке приоритета.
2. Запускает `winws.exe` с очередной стратегией, ждёт прогрев.
3. Проверяет реальный доступ к YouTube и Discord (HTTPS-запросы).
4. Первая стратегия, где оба сервиса доступны, фиксируется и запоминается.

## Как работает Telegram-прокси

Отдельный таб **«Telegram»** управляет локальным MTProto-прокси на базе [tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy) от того же автора (Flowseal). **Движок прокси встроен прямо в ZapretGUI как Python-модуль** (папка `app/tg_proxy_engine/`) — никакого отдельного `TgWsProxy.exe` не скачивается, никакого второго tray-окна не появляется:

1. При нажатии «Запустить прокси» движок запускается как asyncio-задача **внутри процесса ZapretGUI** (в отдельном фоновом потоке). Прокси слушает MTProto-эндпоинт на `127.0.0.1:1443` и туннелирует трафик Telegram через WebSocket к серверам Telegram.
2. GUI сам генерирует и хранит `secret` (32 hex символа) в `%LOCALAPPDATA%\ZapretGUI\tg-ws-proxy\tg_proxy_config.json` — он стабилен между перезапусками.
3. Из `host`/`port`/`secret` строится готовая ссылка `tg://proxy?server=...&port=...&secret=...`.
4. Кнопка **«Открыть в Telegram»** передаёт ссылку ОС — Telegram Desktop открывается и автоматически настраивает прокси. Можно и вручную скопировать ссылку.
5. Чекбокс **«Запускать вместе с zapret»** — при старте zapret-движка прокси тоже поднимается автоматически.

Состояние прокси отображается и в трее (подменю **Telegram**: статус, запуск/остановка, открытие ссылки).

Прокси полностью независим от DPI-обхода zapret — их можно использовать по отдельности.

### Почему встроен, а не как subprocess

В upstream `TgWsProxy.exe` — это **tray-приложение** со своим собственным GUI и иконкой в трее. Если бы мы запускали его как subprocess, в трее появилось бы две иконки: одна от ZapretGUI, вторая от TgWsProxy. Это путало пользователя. Поэтому мы берём только **движок прокси** (`proxy/` и `utils/` модули из upstream) и запускаем его как Python-код внутри нашего процесса — никакого второго приложения, всё управление через один интерфейс ZapretGUI.

## Решение проблем

- **Антивирус ругается на winws.exe / WinDivert** — это ложное срабатывание; добавьте папку zapret в исключения.
- **Ошибка запуска / служба конфликтует** — остановите службу zapret или другой запущенный winws.exe (приложение делает это автоматически перед стартом).
- **Нет стратегий в списке** — проверьте, что указана правильная папка zapret с `.bat`-файлами.
- **Нет доступа после подбора** — обновите стратегии (провайдеры меняют блокировки).

## Тесты

```bat
pip install -r requirements-dev.txt
pytest tests/ -q
```

GUI-тесты используют `pytest-qt` и создают настоящее окно, поэтому их нужно запускать в графической сессии. Если тесты падают с `access violation`, сначала удалите старые `__pycache__` — устаревший байткод от другой версии Python даёт именно такой эффект.
